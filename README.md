# 🧳 타비도리 스팟 수집장

타비도리(Tabidori) 캡스톤디자인 팀 프로젝트의 **여행 스팟 데이터 수집 도구**입니다.
팀원이 조사한 관광지/맛집/카페 등의 정보를 입력하면, CSV로 내보내서 DB에 올릴 수 있는 형태로 모아줍니다.



## 📌 이게 뭐예요?

- 50~60개의 여행 스팟을 조사해서 모으기 위한 **입력 폼(index.html)**
- 입력한 데이터는 브라우저(localStorage)에 임시 저장됨
- "CSV로 내보내기" 버튼으로 엑셀/구글시트에 옮길 수 있는 파일을 만들 수 있음

> ⚠️ 이 폼 자체는 실제 서비스 DB가 아니라, **데이터 수집용 임시 도구**입니다.
> 실제 DB(PostgreSQL)는 별도로 설계되어 있고, 여기서 모은 데이터를 옮겨서 사용할 예정입니다.



## 🚀 사용법

1. `index.html` 파일을 다운받아서 브라우저로 열기 (더블클릭하면 됨)
2. 폼에 스팟 정보 입력 → "+ 다이어리에 담기" 클릭
3. 다 모았으면 "CSV로 내보내기" 클릭 → 팀 공유 시트에 업로드



## 🗂️ DB 설계

스팟(CURATION_SPOTS)과 입장권(ADMISSION_TICKETS) 2개 테이블로 구성되어 있습니다.
자세한 설계는 팀 노션 문서 참고 ([타비도리 DB 설계도](링크 넣기)).

- `CURATION_SPOTS`: 스팟 기본 정보 (이름, 위치, 영업시간, 태그 등)
- `ADMISSION_TICKETS`: 스팟별 입장권 종류 & 요금 (1개 스팟 : 여러 개 티켓)



## 🛠️ 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크 없음)
- 데이터 임시 저장: `localStorage`
- Google Font: Gaegu
